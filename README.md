# Pixelbrew Cafe - First PowerBI Project

This repository contains my first PowerBI project for Pixelbrew Cafe.

## Files Included

- `PixelBrew_Executive_Dashboard.pbix`: The main PowerBI dashboard file.
- `Dim_Customers.csv`: Customer dimension data.
- `Dim_MenuItems.csv`: Menu items dimension data.
- `Fact_Orders.csv`: Orders fact data.
