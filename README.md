# Pixelbrew Cafe - First PowerBI Project

This repository contains my first PowerBI project for Pixelbrew Cafe.

## Files Included

- `PixelBrew_Executive_Dashboard.pbix`: The main PowerBI dashboard file. This file contains the Executive Dashboard which provides high-level business metrics. It features a complete data model connecting the factual order data to customer and menu item dimensions. Key visualizations likely include total revenue, top-selling menu items, customer purchasing trends, and overall sales performance.
- `Dim_Customers.csv`: Customer dimension data. Contains demographic and detail information about the cafe's customers.
- `Dim_MenuItems.csv`: Menu items dimension data. Contains the cafe's product catalog, including item names, categories, and prices.
- `Fact_Orders.csv`: Orders fact data. The core transactional table recording every order placed, including quantities and timestamps, which links to the customer and menu item tables.
